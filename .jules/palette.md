## 2026-09-06 - WinUI 3 DataTemplate CheckBox Accessibility and Truncated Path Tooltips
**Learning:** In WinUI 3 `ItemsControl` and `ListView` templates, `CheckBox` elements with composite children (e.g., `StackPanel` containing icons and `TextBlock` elements) do not inherit an accessible name from their child text blocks, leaving screen readers like Narrator unable to announce what the checkbox controls. Additionally, path `TextBlock` elements with `TextTrimming="CharacterEllipsis"` truncate long folder paths without affording the user a way to inspect the full path.
**Action:** Always bind `AutomationProperties.Name="{x:Bind ...}"` directly on composite `CheckBox` elements in data templates, and add `ToolTipService.ToolTip="{x:Bind ...}"` to truncated text and row items so both screen reader and sighted mouse users can identify and inspect full paths.
