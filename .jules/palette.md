## 2026-09-08 - Accessible Names and Tooltips on Truncated List Items
**Learning:** In WinUI 3 DataTemplate items with `TextTrimming="CharacterEllipsis"` (such as scan results and file path rows), elements get clipped on narrower window sizes without a way for mouse or screen reader users to discern the full content. Adding `ToolTipService.ToolTip="{x:Bind ...}"` provides hover inspection without changing layout, while `AutomationProperties.Name="{x:Bind Summary}"` or `AutomationProperties.Name="{x:Bind Text}"` exposes full descriptions to assistive tools (Narrator/NVDA).
**Action:** When using `TextTrimming="CharacterEllipsis"` in WinUI DataTemplates, bind `ToolTipService.ToolTip` to the source string and specify `AutomationProperties.Name` on interactive item roots or text blocks.
