## 2026-09-06 - Accessible names for WinUI 3 CheckBoxes with composite content and path tooltips
**Learning:** In WinUI 3 desktop applications, when a `CheckBox` contains a complex child panel (such as a `StackPanel` containing multiple `TextBlock` elements) instead of a simple string `Content`, screen readers (Narrator, NVDA) may fail to infer a concise accessible name for the control. Explicitly setting `AutomationProperties.Name="{x:Bind ...}"` provides an immediate accessible name to assistive technologies. Additionally, combining this with `ToolTipService.ToolTip="{x:Bind Path}"` on the CheckBox and `ToolTipService.ToolTip="{x:Bind ParentPath}"` on truncated `CharacterEllipsis` TextBlocks provides hover context for long paths without breaking visual layout.
**Action:** Always set `AutomationProperties.Name` on WinUI `CheckBox` controls that contain composite child layout panels, and pair truncated `CharacterEllipsis` paths with `ToolTipService.ToolTip`.
