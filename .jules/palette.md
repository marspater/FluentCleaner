## 2026-09-06 - WinUI 3 CheckBox Screen Reader Names and Truncated Text Inspection
**Learning:** In WinUI 3 desktop applications, when a `CheckBox` hosts layout panel children (e.g. `StackPanel`) instead of a plain string `Content`, screen readers (such as Windows Narrator and NVDA) cannot infer the accessible name automatically, causing the control to be read as an unnamed checkbox. Explicitly binding `AutomationProperties.Name="{x:Bind ...}"` to the item name provides full accessibility without altering visual presentation. Additionally, interactive list views with `TextTrimming="CharacterEllipsis"` truncate long paths and app names; pairing them with `ToolTipService.ToolTip="{x:Bind ...}"` allows users to inspect the full text effortlessly on hover.
**Action:** Always specify `AutomationProperties.Name` when templating `CheckBox` controls with complex content, and ensure `TextBlock` elements with `TextTrimming="CharacterEllipsis"` include `ToolTipService.ToolTip`.
