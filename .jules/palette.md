## 2026-09-06 - Accessible names and tooltips in composite CheckBox items
**Learning:** In WinUI 3, when a `CheckBox` wraps a composite layout panel (such as a `StackPanel` containing header and caption `TextBlock`s), accessibility screen readers (Narrator/NVDA) cannot automatically infer an accessible name from text content. Adding `AutomationProperties.Name="{x:Bind ...}"` to the `CheckBox` provides a direct accessible label. Furthermore, for truncated path `TextBlock`s styled with `TextTrimming="CharacterEllipsis"`, binding `ToolTipService.ToolTip="{x:Bind ...}"` allows users to easily inspect the full unclipped path without layout shifts.
**Action:** When creating composite CheckBox items in ListView DataTemplates, always set `AutomationProperties.Name` on the CheckBox and `ToolTipService.ToolTip` on truncated text elements.
