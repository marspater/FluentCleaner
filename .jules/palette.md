## 2026-09-07 - Empty State Call-to-Action and Card Toggle Accessibility
**Learning:** Empty states that advise users to create new items (such as Custom Cleaners) create friction when they omit an inline primary action button, requiring users to hunt for secondary actions in title bar overflow menus (`[...]`). Providing an inline AccentButton connected to existing creation flows resolves this immediately. Additionally, WinUI `ToggleSwitch` controls rendered inside card `DataTemplate` items with empty `OnContent`/`OffContent` are announced without a label by screen readers unless `AutomationProperties.Name` is explicitly bound (e.g., `{x:Bind Name}`).
**Action:** Always provide an actionable primary CTA button within empty state panels and ensure `ToggleSwitch` controls inside item templates bind `AutomationProperties.Name` to their entity name.
