## 2026-09-06 - Composite CheckBox Labels and Truncated Path Tooltips in WinUI 3 DataTemplates
**Learning:** In WinUI 3 `DataTemplate` items, wrapping layout panels (such as `StackPanel` containing icons and `TextBlock`s) inside a `CheckBox` causes UI automation trees to lose accessible name associations, leaving screen readers (Narrator/NVDA) to announce them as unlabeled checkboxes. Explicitly setting `AutomationProperties.Name="{x:Bind ...}"` restores accessible naming without visual side effects. Furthermore, secondary path labels rendered with `TextTrimming="CharacterEllipsis"` inside list cards obscure full file paths from users unless paired with `ToolTipService.ToolTip="{x:Bind ...}"`.
**Action:** When a `CheckBox` hosts layout panel children or when path `TextBlock`s use `TextTrimming="CharacterEllipsis"` within WinUI 3 `DataTemplate`s, always bind `AutomationProperties.Name` and `ToolTipService.ToolTip` to provide full accessibility and hover discovery.
