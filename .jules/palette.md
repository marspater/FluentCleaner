## 2026-10-25 - WinUI 3 Accessible Names for Composite CheckBoxes and ToggleSwitches
**Learning:** In WinUI 3 desktop applications, when `CheckBox` controls contain complex layout children (such as `StackPanel` or `TextBlock` grids) or `ToggleSwitch` controls have empty `OnContent`/`OffContent` strings, screen readers (Narrator/NVDA) do not automatically deduce an accessible name. Setting `AutomationProperties.Name` directly on the `CheckBox` or `ToggleSwitch` control is necessary for screen readers to announce the control's label during keyboard focus navigation.
**Action:** Always specify `AutomationProperties.Name="{x:Bind ...}"` or static label string on `CheckBox` controls with child panels and `ToggleSwitch` controls with empty content properties in WinUI 3 XAML views.
