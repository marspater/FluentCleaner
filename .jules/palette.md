## 2026-09-08 - Accessible Names for WinUI 3 Controls with Blank Headers or On/Off Content
**Learning:** In WinUI 3 desktop applications, `ToggleSwitch` elements configured with empty string content (`OnContent="" OffContent=""`) or placed without an explicit `Header` attribute do not emit an accessible name to UI Automation. Screen readers such as Narrator and NVDA announce them ambiguously as unlabeled switches (e.g. "Toggle switch, off"). Similarly, `ComboBox` elements styled inside cards without an explicit `Header` require `AutomationProperties.Name` to provide context.
**Action:** When creating or styling `ToggleSwitch` or `ComboBox` controls with suppressed visual headers or empty on/off text, always specify `AutomationProperties.Name` (static text or bound via `{x:Bind ...}`) to guarantee screen reader accessibility.
