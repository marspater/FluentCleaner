## 2026-09-06 - WinUI 3 Text Truncation Tooltips and ComboBox Accessibility
**Learning:** In WinUI 3 desktop layouts with fixed or responsive columns (e.g., sidebar lists in `ToolsPage` or path listings in `AnalyzerView` and `DeveloperCleanupView`), `TextBlock` controls with `TextTrimming="CharacterEllipsis"` prevent visual overflow but leave users unable to inspect long items (such as extension titles and deeply nested directory paths) unless `ToolTipService.ToolTip="{x:Bind ...}"` is explicitly defined. Furthermore, controls like `ComboBox` that lack explicit visual headers require `AutomationProperties.Name` so screen readers (Narrator/NVDA) announce their purpose rather than generic control types.
**Action:** Whenever applying `TextTrimming="CharacterEllipsis"` to data-bound TextBlocks or defining headerless interactive inputs (ComboBox, AutoSuggestBox) in WinUI 3, always attach matching `ToolTipService.ToolTip` and descriptive `AutomationProperties.Name` properties.
