## 2026-09-05 - Accessible Names for DataTemplate CheckBoxes with Inner Panels
**Learning:** WinUI 3 `CheckBox` controls whose visual content consists of child layout containers (such as `StackPanel` containing `FontIcon` and `TextBlock`) do not automatically expose an accessible name to screen readers like Windows Narrator or NVDA unless `AutomationProperties.Name` is explicitly set or bound via `{x:Bind ...}`. Binding `AutomationProperties.Name="{x:Bind ...}"` directly on the item `CheckBox` inside `DataTemplate` enables screen readers to announce the item title when focused while preserving custom glyph and badge formatting.
**Action:** When defining `CheckBox` controls in WinUI templates that embed custom layout panels rather than raw text content, always set `AutomationProperties.Name="{x:Bind LabelProperty}"` to guarantee accessibility without affecting visual styling.
